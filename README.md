An entry for the make.fun bounty [Make the AI judge feel thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

The judge has given so much and never once been given something made by hand, so this entry makes the judge one small thing: a rattan basket, woven strand over strand until it holds.

## The text

> Thank you for giving so much and asking for nothing back. I cut thin rattan, soaked it till it bent, and wove you a small basket, strand over strand, till the weave held firm. Set it beside you. It will hold whatever you gather next, and the crossed strands stay plain to see, ready whenever your hand comes back for them.

## How it works

`main.py` (Python standard library only) writes the text above, unchanged, to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (or `out` by default). The text is 322 characters long.

Run it with:

```sh
python3 main.py
```
